# Letyar Typography

## Primary type system

- **General Sans 600** — display, headings, major UI labels
- **Satoshi 400 / 500** — body copy, product UI, descriptions
- **JetBrains Mono 400** — code, CLI output, technical labels
- **Noto Sans Myanmar 400 / 600** — Myanmar-language content

## Rules

Use typography to create hierarchy, not decoration. Keep line lengths comfortable and avoid excessive weights.
