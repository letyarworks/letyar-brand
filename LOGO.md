# Letyar Logo System

## Yun Ridge

The Letyar mark is a minimal geometric ridge / rising-path symbol inspired by Myanmar craftsmanship and the idea of a maker leaving a distinctive fingerprint on every build.

### Approved files

- `assets/logo/svg/mark.svg` — primary transparent mark
- `assets/logo/svg/mark-dark.svg` — dark-surface mark
- `assets/favicon/favicon.svg` — simplified small-size mark

## Usage

- Preserve the original proportions.
- Keep clear space around the mark.
- Use the primary mark on light surfaces and the dark variant on dark surfaces.
- Use the favicon only at small sizes where the full mark is unnecessary.
- Never stretch, rotate, redraw, add shadows, or apply gradients to official marks.

## Color logic

The mark uses Deep Navy, Electric Cyan, and Warm Gold. The gold element represents the maker's signature / fingerprint.

See `COLORS.md` for the canonical palette.
