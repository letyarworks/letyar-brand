# LETYAR — PROFILE & SOCIAL ASSET SET

`letyarlabs.com` · `@letyarworks`

This asset pack contains profile/avatar vectors and raster exports plus social cover/banner artwork.

## Profile avatars

The avatar artwork is derived from the Letyar Yun Ridge mark.

- `A-cream/` — cream background, ink mark, lacquer-red signature dot
  - Intended for dark UI surfaces such as X, GitHub dark, and Discord.
- `B-ink/` — ink background, cream mark, orange-red signature dot
  - Primary profile treatment for light UI surfaces such as LinkedIn, npm, Gmail, and Notion.
- `C-lacquer/` — lacquer-red background, cream mark, ink signature dot
  - Intended for Instagram, YouTube, and Facebook Page.

PNG exports: `1024 / 512 / 400 / 200 / 128 / 64 / 32 px`.
The 64px and 32px versions use the simplified two-groove treatment.

## Vector masters

`svg/` contains scalable avatar vector masters:

- `letyar-avatar-a-ink.svg`
- `letyar-avatar-b-cream.svg`
- `letyar-avatar-c-lacquer.svg`

## Banners

The `banners/` directory contains platform-specific artwork for:

- X header
- LinkedIn cover
- GitHub social preview
- Open Graph image
- Facebook cover
- YouTube channel art

The banner artwork keeps important text inside platform-safe areas where applicable.

## Important brand note

These profile/social assets preserve the supplied heritage palette (`#16130F`, `#FAF7F0`, `#B23A22`). The current Letyar digital product palette is documented separately in `COLORS.md`; these heritage colors remain available as an intentional heritage/identity treatment.
